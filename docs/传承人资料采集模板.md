# 传承人资料采集模板

> 用途：为《碎瓷重圆》采集真实匠人、传承人或研究者的口述与引述。
> 每采集一位受访者，复制一份本模板填写，存入 `docs/访谈/` 目录（人工保管）。
> 规则：**页面只呈现经人工核实并注明授权范围的条目**；未核实前，`src/data/quotes.js`
> 中对应条目必须保持 `pending: true`，页面称谓为「传承资料摘记 · 待核实」。

## 一、受访者信息

| 字段 | 内容 |
| --- | --- |
| 姓名或匿名身份 | （如需匿名，写「景德镇锔瓷匠人 W」并另行保管真名） |
| 职业 / 工种 | （如：把桩师傅 / 锔瓷匠 / 陶瓷史研究者 / 博物馆讲解员） |
| 与项目的关系 | （受访 / 提供书面资料 / 授权图片等） |
| 联系与归属机构 | （可留空；仅人工档案留存，不上页面） |

## 二、采访记录

| 字段 | 内容 |
| --- | --- |
| 采访日期 | YYYY-MM-DD |
| 地点 | （线上 / 线下具体地点） |
| 采访者 | |
| 采访形式 | （面谈 / 电话 / 书面 / 影像） |
| 原始文件路径 | （录音 / 录像 / 笔记的本地归档路径，人工保管） |

## 三、授权范围

| 字段 | 内容 |
| --- | --- |
| 公开授权范围 | （页面展示 / 仅答辩现场 / 仅内部存档） |
| 允许使用姓名 | ☐ 是 ☐ 否（匿名） |
| 允许使用声音 | ☐ 是 ☐ 否 |
| 允许使用影像 | ☐ 是 ☐ 否 |
| 授权方式与日期 | （书面 / 微信确认截图存档路径 / 口头+事后书面） |

## 四、内容

**原话（逐字，含口误与语气词，人工保管，不上页面）：**

> 

**页面节选（拟上线的文字，须逐字引自原话或明确标注「根据资料概括」）：**

> 

**拟在 `src/data/quotes.js` 中的结构化条目：**

```js
{
  site: 'yuyao',            // yuyao / guyao / taoxichuan
  pending: true,            // 人工核实后改为 false
  quoteType: 'verbatim',    // verbatim 逐字 / summary 概括（概括时页面自动加「根据相关资料概括」）
  authorization: 'granted', // public / granted / pending / n/a
  accessedAt: 'YYYY-MM-DD',
  speaker: '',
  speakerRole: '',
  sourceType: '访谈',       // 官网资料 / 出版物 / 纪录片 / 访谈
  sourceTitle: '',
  url: '',
  text: ''
}
```

## 五、人工核实

| 字段 | 内容 |
| --- | --- |
| 核实人 | |
| 核实日期 | |
| 核对内容 | ☐ 原话与节选一致 ☐ 授权范围明确 ☐ 页面称谓正确（非「真实传承之声」） |
| 结论 | ☐ 可上线（改 pending: false） ☐ 需补充材料 ☐ 不采用 |
