# 《碎瓷重圆》六屏沉浸 UI 设计规范

## 1. 设计规范

视觉命题：把修复室作为一个静谧的舞台，让器物成为视线中心。开始页以竖排标题、中央青花瓶、右侧玻璃卡建立三层空间。其余界面围绕同一器物切换，不重建 WebGL 渲染器。

### 色板

| Token | 颜色 | 用途 |
|---|---|---|
| blue | #2c4a7c | 青花纹样、按钮、证书正文 |
| paper | #faf8f3 | 标题、纸张与高光 |
| clay | #f5f2ea | 瓷胎、记忆卡，作为纸白的材质变体 |
| gold | #c9a961 | 裂线、细框、进度与少量点缀 |
| ink | #1a2332 | 沉浸背景，作为环境底色 |

青花蓝、纸白、金构成三种主色关系。墨蓝用于空间；米白属于纸白材质变体。印章使用极小面积的暗朱色，呼应参考图。

### 字体、间距与层级

- 字体：SimSun → Songti SC → Noto Serif SC → serif；英文字母与编号使用 Arial / monospace。采用系统字体，无外部字体请求。
- 开始页标题：54—94px，竖排，字距16px；手机48px、字距9px。界面标题26—34px，正文12—14px，辅助索引9—11px。
- 间距：8px 基准；卡片24—36px；桌面画面两侧留白5—8%；卡片正文行高2—2.3。
- 背景：translateZ(-200px)，指针系数0.2；器物：translateZ(-50px)，系数0.5；卡片：translateZ(50px)，系数0.8。
- 透视：1200px；悬浮卡片局部 rotateX / rotateY 最大±8°，以 GSAP 0.5秒缓动跟随。
- 表面：玻璃卡渐变半透明、16px backdrop blur、双重细框；证书和记忆卡使用纸白与噪点；瓷瓶使用 MeshPhysicalMaterial、clearcoat=1。

## 4. 声音与降级

声音默认关闭，点击后启用 Web Audio：吸附三角波叮声、低通噪声窑火、低音开窑意象、五声调式合成拨弦背景。它们为合成氛围声音，并非真实古琴录音。可随时关闭。

- 粒子：桌面110个背景点，移动/低核45个；瞬态粒子最多150个，合计≤260。开始页另有9个几何瓷片。
- 移动端pixelRatio≤1.5；触屏拖拽；方向感应需用户点击授权。没有陀螺仪时保留触屏。
- 低性能关闭Bloom和玻璃模糊，减少粒子。连续慢帧达到阈值后进一步降至pixelRatio≤1.25。
- 后处理只有Bloom及颜色/透明度输出处理，没有SSAO或DOF。
- WebGL不可用时，CSS瓶形与CSS瓷片支持简化拖动拼合、记忆、选择与导出；没有真实3D材质与Bloom。
- 系统减少动态效果时关闭视差与循环动效，转场立即完成。

目标60fps；实际帧率须在目标手机与GPU测量，不能由构建通过推断。当前是可运行界面原型：程序化纹样与旋转瓶体，不含参考图级照片材质、真实考据或复杂物理。
