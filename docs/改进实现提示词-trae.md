## 提示词正文

你是《碎瓷重圆》项目的开发工程师。这是一个 Web 端青花瓷修复互动作品（Three.js + Vite + 原生 JS），准备参加"民族文化创新表达"作品赛项，现在需要按下面的任务清单完成一轮改进。请先通读本提示词和项目现有代码，再动手。

### 项目背景（必读）

- 作品立意：修复一件瓷器，接续一段生活，让一门手艺被更多人记住。玩家在网页上拼合碎瓷、聆听器物的第一人称记忆、选择修复方式（锔瓷/金缮/不修复），最后获得带篆印的证书，并可解锁御窑厂/古窑/陶溪川三处写实 3D 考察点。
- 主流程入口 `index.html`，主控逻辑在 `src/immersive.js`，界面样式在 `src/immersive.css`。
- 数据核心 `src/data/vessels.js`：6 件瓷器（每件 8 段记忆）、3 处考察点。每件器物的 `proto` 字段挂故宫馆藏原型参考卡。
- 关键模块：`src/modules/`（fragments 拼合、textures 纹理、audio WebAudio 合成音、certificate 证书、vessel-model 真实 GLB 加载）、`src/kaocha/`（写实考察 3D）、`src/modules/workshop-art.js`（Canvas 程序化美术：水墨远山、篆印 sealImage()）。
- 构建：`npm run dev` 开发、`npm run build` 产物在 `dist/`（相对路径可放任意子目录）、`npm run models` 由根目录中文名高模生成网页优化 GLB 副本到 `public/models/`。测试 `npm test`（改数据后必须跑）。
- 设计约束：碎片只在 XY 平面拖拽；禁止物理引擎；模型加载失败静默回退程序化器身；localStorage 存进度（key: porcelain-reunion-progress-v1）。
- 素材红线：不引入任何外部商用图库、老照片或 AI 生成图片；新增视觉一律用 Canvas/SVG 程序化绘制或复用现有程序化资产；文案涉及史实/传说的必须分层标注，不得宣称虚构器物为真实馆藏。

### 验收标准（全部任务通用）

1. `npm test` 全绿；`npm run build` 通过（网页版静态产物）。
2. 新增页面/功能在 Chrome 桌面端与手机宽度（375px）下均可正常显示与操作。
3. 所有新增视觉素材均为 Canvas/SVG 程序化生成或复用现有资产，零新增外部图片；如确需外部资源，先停下来向人工说明。

5. 不改动现有主流程手感（吸附判定常量、碎片拖拽约束、进度链 unlockAt 2/4/6）。
