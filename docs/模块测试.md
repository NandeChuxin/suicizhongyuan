# 模块实现与测试方法

所有模块均为可运行 ES Module，统一由 src/main.js 接入。安装依赖后，`npm run dev` 运行游戏，`npm test` 运行 Node 测试。

| 模块 | 可运行代码 | 自动验证 | 人工测试方法 |
| --- | --- | --- | --- |
| 瓷片生成 | src/modules/fragments.js | 覆盖瓶形面积、UV 对齐、非空几何、双向邻接、Z 为零、散落不出界 | 开始后观察九块不规则瓷片；完成后检查纹样衔接与空洞 |
| 拖拽与旋转 | src/modules/interaction.js | 浏览器测试实际派发 touch pointerdown/move/up、Q/E、右键旋转、pointercancel、输入框按键 | 鼠标和手机分别拖动，检查按下无瞬移、转动角度一致、取消拖拽无锁定 |
| 吸附与完成 | src/modules/gameState.js + main.js | 距离与角度同时判定、整圈角差、阈值边界、锁定去重、九片完成 | 正确角度但位置错误不吸附；正确位置但角度差大不吸附；接近两者时 0.2 秒归位 |
| 碎片记忆 | src/data/storyData.json + modules/memories.js | 60—120 字、唯一绑定、文件存在；浏览器逐片解码图片并检查弹卡、9/9 记忆册回看 | 每片归位后有对应图文；重置后记忆数归零，卡片关闭 |
| 修复抉择 | src/modules/repair.js | 浅灰/金色可见性、线宽、透明度、Bloom 开关、不同文案 | 拼完选择传统，观察低透明浅灰线；再改金缮，观察金线加宽与泛光 |
| 上釉补色 | src/modules/scene.js + main.js | 浏览器流程检查完成后到 ready 与签发状态 | 选择后上釉，青花逐渐显现；动画中重置不会弹回完成页 |
| 修复证书 | src/modules/certificate.js | 日期时区、编号稳定与重新签发、昵称纯文本；浏览器检查 2 张截图、实际 html2canvas PNG | 输入昵称→完成→预览，检查署名/日期/编号/理念/特写；下载后用图片查看器确认 PNG |

## Node 模块测试

```powershell
npm test
```

7 项测试的源代码位于 tests/modules.test.js。测试无需浏览器或 WebGL，使用 Three.js 几何与状态对象。

## 浏览器集成测试

```powershell
npm run dev
```

打开 `/tests/browser.html`，点击“运行验收”。该页面导入正式游戏模块，确定性设置初始瓷片变换后，通过正式的 Raycaster 和 pointer 处理器完成九片归位。所有锁定、记忆计数、修复选择和证书签发都走正式代码。

测试包括昵称输入、触屏拖拽、旋转、取消、九段纹样图片解码、记忆册回看、两种视觉与文案、HTML 注入隔离、证书截图与 PNG 下载。测试会快进动画，不作为性能或真实触摸硬件的测量。

此页面只用于开发，不进入生产构建 dist。

## 人工回归

- 初始页、委托页、记忆卡、选择页、完成区文字不被裁切。
- 手机竖屏时旋转/提示工具条固定在底部；手记卡能滚动、继续按钮可点击。
- 点击锁定瓷片不会重新移动；只用提示不会改变进度。
- 开关声音、重置、重新选择修复方式、重复下载均不报错。
- 修复中改变浏览器尺寸，未锁定瓷片仍可拾取；锁定位置和纹样不变化。
- 导出后游戏相机与画布大小恢复；传统证书无金线 Bloom，金缮证书包含金色裂纹。
