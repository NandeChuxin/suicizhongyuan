# 网页访问与部署说明

> 本作品是**纯网页应用**：观众无需下载或安装任何客户端、App、插件或运行时，
> 用浏览器打开网址即可使用。构建与部署由开发者（人或 AI）完成；**实际域名与上线动作由人工执行**。

## 一、访问方式

- 根目录部署：`https://<你的域名>/`
- 子目录部署：`https://<你的域名>/porcelain/`
- 生产构建使用相对资源路径（`base: './'`），放在任意静态托管的根目录或子目录都可直接访问；
- 页面使用 hash 路由（`#cabinet`、`#puzzle` 等），静态托管**无需**配置 SPA 重写；
- 首次打开需要联网加载页面与模型；本作品**不注册 Service Worker、不提供离线缓存，也不提供安装引导**。

## 二、构建

### 1. 公网版（推荐公网发布）

```powershell
# PowerShell
$env:VITE_ONLINE_MODE = "1"; npm run build; Remove-Item Env:VITE_ONLINE_MODE

# cmd
set VITE_ONLINE_MODE=1&& npm run build

# bash / Git Bash
VITE_ONLINE_MODE=1 npm run build
```

公网版差异：器物纹理走 Canvas 程序化兜底层，原型参考卡只显示文字出处、不展示馆藏照片
（逻辑见 `src/config.js` 与 `src/immersive.js`）。**公网部署一律使用此模式。**

### 2. 完整版（含馆藏原型照片，仅限非商业教育演示）

```powershell
npm run build
```

产物同为 `dist/` 纯静态网页。馆藏照片授权仅覆盖非商业教育演示场景，**不得用于公网或商业传播**；
如需内部演示，可用任一静态服务器托管 `dist/` 供局域网浏览器访问，但这仍是网页访问，不是离线分发包。

### 3. 前端资源

- 构建前 `prebuild` 会自动收集第三方许可声明到 `dist/THIRD_PARTY_NOTICES.txt`；
- `dist/models/`（`hero.glb` 与 `vessels/*.glb`）必须与页面一同上传；缺少时页面不报错，
  但会静默回退到程序化器身；
- `dist/patterns/`、`dist/og-cover.svg` 等静态资源随 `dist/` 一并上传即可。

## 三、托管要点

1. **静态托管即可**：Nginx / Apache / GitHub Pages / Vercel / Netlify / 对象存储 + CDN 均可；
   服务端只需正确返回静态文件；
2. **MIME**：`.glb` 建议返回 `model/gltf-binary`，`.js` 为 `text/javascript`，`.svg` 为 `image/svg+xml`；
3. **缓存**：`index.html` 建议 `no-cache`；`assets/` 为带 hash 的构建产物，可长缓存；
4. **正式二维码**：把正式地址生成的二维码图片替换 `public/share-qr.png` 后重新构建；
   未替换时会自动回退为程序化占位二维码（页面有说明文字）；
5. **社交分享图（og:image）**：
   - `index.html` 中的 `og:image` 当前为相对路径，正式域名确定后改为**绝对 HTTPS 地址**；
   - 社交平台普遍不支持 SVG，推荐输出 1200×630 PNG/JPG 作为分享图；
6. **旧 PWA 缓存清理（仅当此前部署过带 Service Worker 的版本）**：
   浏览器可能仍保留旧离线缓存。可先临时发布一个只做清理的 `sw.js`，等老访客完成一次访问后再删除：

   ```js
   self.addEventListener('install', () => self.skipWaiting());
   self.addEventListener('activate', async () => {
     const keys = await caches.keys();
     await Promise.all(keys.filter(k => k.startsWith('pr-cache-')).map(k => caches.delete(k)));
     await self.registration.unregister();
   });
   ```

   本仓库当前版本已不含 `sw.js` / `manifest.webmanifest` / 图标等安装与离线资源。

## 四、部署后检查清单

- [ ] 打开正式网址：首页 GLB 正常加载；临时改名 `models/` 目录后刷新，应静默回退程序化器身（无报错弹窗）；
- [ ] 六件器物拼合 → 长卷 → 证书 → 下载证书 / 分享卡 / 展签 / 器物档案均可用；
- [ ] 二维码指向正式地址且可扫码打开；
- [ ] 手机（375px 宽度）无横向溢出、无不可点击控件；
- [ ] `localStorage` 键 `porcelain-reunion-progress-v1` 正常存取进度；
- [ ] 分享 meta 在微信/QQ 内分享卡片显示正常（og:title / og:description / og:image）；
- [ ] 服务器返回 `404` 时不会用 HTML 冒充 JS/GLB（避免 MIME 报错）。

## 五、明确不做（由人工决定时机）

- 实际的域名购买、DNS、托管平台操作与上线动作；
- 正式二维码的生成与替换决策；
- 移动端真机的最终验收记录（配合 `docs/改进验收.md` 的「尚需人工完成」清单）。
