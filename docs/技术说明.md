# 技术说明

## 生成与坐标

瓶形是正面的非凸二维轮廓。先用 THREE.ShapeUtils.triangulateShape 对轮廓三角剖分，再把每个三角形与 d3-delaunay 生成的 Voronoi 单元相交。相交多边形转为 THREE.BufferGeometry，避免直接用 Voronoi 矩形代替瓶形而留下空洞。

每片局部顶点 = 全局顶点 − 该单元站点；correctPosition 存储站点。UV 从同一个全局坐标范围计算，因此全部拼回时纹样连续。一个 CanvasTexture 被所有瓷片材质共享。

fragment = { mesh, seams, correctPosition, correctRotation, locked, adjacent, storyId, revealed }。

gameState = { phase, repairMode, repairedCount, totalCount, fragments, userName, certificateId, certificateDate, unlockedStories }。

故事存储在 storyData.json，结构为 { id, title, text, image }。

## 拾取、旋转与吸附

正交相机面向 XY 平面。Raycaster 拾取未锁定 Mesh，屏幕 pointer 坐标与 Z=0 平面求交。拖拽保存“瓷片位置 − 按下时交点”的偏移，避免按下瞬移。瓷片 position.z 全程为零，选中层级由 renderOrder 处理。

旋转只修改 rotation.z。Q/E 与触屏按钮增减 15°；右键位移映射为角度。角差用 atan2(sin(a), cos(a)) 归一化，正确处理 360° 跨界。

吸附同时要求 XY 距离 < 0.6、绝对角差 < 12°，不能凭任一条件锁定。GSAP 在 0.2 秒内归位。锁定去重后，更新进度、revealed 和 unlockedStories，再显示手记卡。最后一段手记关闭后进入修复抉择。

## 模式、视觉与补色

裂纹来自 Voronoi 边线在瓶形三角形内的裁剪段；剔除 Voronoi 外接矩形边，避免把瓶外轮廓当裂缝。

传统模式使用低透明度 LineSegments，Bloom 关闭。金缮模式用几何宽度 0.042 世界单位的带状三角形加宽裂线；不依赖 WebGL 通常不支持的粗 linewidth。

金线使用高动态范围色值，Bloom 阈值高于瓷面，避免整个白瓷被泛光淹没。ACES tone mapping 控制亮度。立体感来自纹理上的自制横向明暗渐变、层级和局部泛光，无真实自由三维视角或物理碰撞。

MeshBasicMaterial 的 onBeforeCompile 加入 uGlaze，把中性的瓷面和同一青花贴图混合；上釉时从 0.68 到 1 动画，表现补色逐渐清晰。这是数字视觉表达，不是釉层材料仿真。

背景 Points 为 90 个。归位和完成的粒子短暂上飘，结束后移出场景并释放几何、材质。提示也在结束后释放临时材质，复用瓷片几何。

## 证书

WebGLRenderer 配置 preserveDrawingBuffer:true。导出时暂时用 600×900 画布和匹配比例相机渲染瓶身，再用 600×600 方形视域渲染中心裂痕特写。先 renderer.render，再 composer.render，读取 toDataURL；因此证书保留所选模式的后处理。

截图完成后在 finally 恢复相机、尺寸、像素比和轮廓可见性。捕获阶段不等待异步帧，合成阶段禁止重复导出和重置。

离屏 HTML 容器用 textContent 填入昵称和证书字段，不将用户输入拼成 HTML。html2canvas 以 2 倍分辨率生成 PNG，实际证书宽 1280 像素。预览和下载使用相同合成函数。

编号采用浏览器 crypto.randomUUID；同一次签发的重复下载稳定。更改修复方式后清空签发信息，上釉完成后生成新编号。日期明确使用 Asia/Shanghai。

html2canvas 按导出需求动态载入，减少首屏下载。运行时字体、图片均不依赖外部站点。

## 状态与重置

状态流程：welcome → commission → playing → choice → finishing → glazing → ready。记忆册可随时回看已解锁记录，导出期间阻止重入。

每次重置递增 session，终止演示 timeline、碎片和裂线补间，清除提示、粒子、记忆、模式、证书。旧动画完成回调检查 session，避免重置后错误跳回完成页。

当前状态在内存中，不保存个人数据到服务器；刷新会重新开始。昵称只用于本次证书。无需账号或后台。
