## 3. 归位判定

**文件**：`src/modules/gameState.js`（顶部三常量，第 1–3 行）

```js
export const SNAP_DISTANCE  = 0.16;        // 吸附距离阈值
export const SNAP_ANGLE     = Math.PI/15;  // 吸附角度阈值 = 12°
export const MAGNET_DISTANCE= 0.72;        // 磁感阶段一（提示性偏向）距离
```

| 阈值 | 值 | 说明 |
|---|---|---|
| **距离阈值** | `SNAP_DISTANCE = 0.16` | 2D 世界单位，`canSnap` 判据 |
| **角度阈值** | `SNAP_ANGLE = Math.PI/15 ≈ 0.2094 rad` = **12°** | `canSnap` 判据 |
| 磁感距离 | `MAGNET_DISTANCE = 0.72` | 仅阶段一青光提示 + 弹性偏向（.12 lerp），**不吸附** |

- **`normalizeAngle(value)` 口径**：`Math.atan2(Math.sin(value), Math.cos(value))`，把角度归一到 **(−π, π]**，避免跨 ±π 的假偏差。
- **`canSnap(fragment)` 判定**（第 9 行）：`if (fragment.locked) return false;` 再取 `position/rotation`，条件为
  `Math.hypot(position.x - correctPosition.x, position.y - correctPosition.y) < 0.16` **且** `Math.abs(normalizeAngle(rotation.z - correctRotation)) < Math.PI/15`。
  注意：2D 判定使用 `distance/rotation.z`；3D 路径另由 `puzzle3d.js` 的 `magnetStage3D` 两阶段判定，`immersive.js` 第 125 行 `const ready=angle<Math.PI/18;`（=10°）仅用于"纹路接上"音频/文案提示，**不是吸附阈值**。

**文件**：`src/modules/fragments.js`

- **`createFragments(texture, stories, options)`**（第 51 行）：参数化 Voronoi 切割管线。每片返回对象字段确认为：
  - `mesh`（`THREE.Mesh`，平面 `BufferGeometry`，顶点 `z` 恒为 0）、`seams`
  - **`correctPosition: new THREE.Vector3(...origin, 0)`**（正确位置，z=0）
  - **`correctRotation: THREE.MathUtils.degToRad(rotationMap[id] ?? 0)`**（正确旋转角，弧度）
  - **`locked: false`**、`adjacent: Array.from(delaunay.neighbors(id))`（邻接片索引）
  - `storyId`、`revealed: false`、`mesh.userData.id = id`
- **平面确认**：顶点压入 `vertices.push(p[0]-origin[0], p[1]-origin[1], 0)`（第 66 行），`mesh.position.set(...origin, 0)`（第 85 行）→ 2D 碎片确为 **z=0 平面**。
- **`scatterFragments(fragments, camera, random)`**（第 103 行）：均分上下两排，随机旋转 ±180°，落位后调用 `confineFragment`。
- **`confineFragment(fragment, camera)`**（第 93 行）：按旋转后的包围盒四角投影夹取，把 `position.x/y` 钳制在相机可视范围内，**并强制 `position.z = 0`**（第 99 行）。

## 4. 3D 展示与考察模块

### 4.1 `src/modules/vessels3d.js`

- `vesselProfile(outline)`（第 6 行）：取 `x≥-0.01` 的右半轮廓 → `Vector2(max(r,.02), y)` → 按 y 升序并去重（相邻 y 差 >0.01 才保留）→ 供 `LatheGeometry` 车削。
- `radiusAt(profile, y)`（第 15 行）：分段线性插值求某高度处半径；越界回退 `profile[0].x ?? .6`。
- `buildVesselMesh(vessel, texture, {mode, physical})`（第 61 行）：`LatheGeometry(profile, 80)` 车削 80 段；**改写 UV 的 v 为实际高度比**（`(position.y - minY)/height`）使纹带贴合肩颈；材质 `physical ? MeshPhysicalMaterial(clearcoat:1, roughness:.22) : MeshBasicMaterial`；`mode` 非空时叠加 `buildSeams`。
- `buildSeams(profile, mode='kintsugi', seed=7, count=7)`（第 30 行）：`SEAM_MODES` 四档——
  - `traditional`：色 `0xbcc1c8`、boost .55、radius .008
  - `kintsugi`：色 `0xc9a961`、boost 2.5、radius .013
  - `juci`：色 `0x8f744b`、boost 1、radius .006（另生成 `[-.09,0,.09]` 三齿跨裂锔钉）
  - `preserve`：色 `0x6e7884`、boost .3、radius .006
  用 LCG（`a*1664525+1013904223`）生成 count 条 `TubeGeometry` 沿器身环绕，`juci` 额外在每个缝加钉。

## 9. 约束清单（既有约束，逐条）

来源：`交接说明.md`（第 99–107 行「关键设计约束」）、`docs/改进实现提示词-trae.md`（第 18–19 行）、`docs/最终改进提示词.md`（第 226–239 行「明确不做」）、`README.md`（第 45–53、64 行）。

**A. 交互/技术约束**

1. 碎片只在 **XY 平面**拖拽（Z 恒 0）；
2. **禁止物理引擎**；**禁止自由漫游 3D**；
3. 磁感分两段：阶段一仅弹性偏向 + 青光提示（**不吸附**），阶段二距离 + 角度双达标才吸附；
4. 每件瓷器 8 段记忆 ↔ 8 个时间轴点；**碎片数(8/10/12)与记忆数是两套计数**；
5. 模型加载失败**静默回退**程序化器身，不阻塞流程；
6. localStorage 存进度，key = `porcelain-reunion-progress-v1`；
7. 进度链：修满 2/4/6 件依次开放御窑厂/古窑/陶溪川；六件全修并走遍三处触发终局成就；
8. 隐藏结局「不修复」(preserve) 是完整结局，不影响证书与进度；
9. 运行时**没有外部图片、字体或 AI 服务依赖**；通过 HTTP(S) 访问，不直接用 file:// 打开 index.html。

**B. 素材/内容红线**

10. **不引入任何外部商用图库、老照片或 AI 生成图片**；新增视觉一律用 **Canvas/SVG 程序化绘制**或复用现有程序化资产；
11. 原型参考图来自故宫博物院官网公开藏品资料（见 `public/patterns/real/ATTRIBUTION.md`），**仅限非商业教育演示**；
12. 线上公开版设 `VITE_ONLINE_MODE=1`：**停用馆藏照片**，只保留文字出处；
13. 文案涉及史实/传说**必须分层标注**（史实依据/民间传说/原创叙事/数字示意/待人工核实），**不得宣称虚构器物为真实馆藏**；不使用"真实故事""真实还原"等称谓；
14. 传承资料摘记全部"**待人工核实**"，不得冒充逐字引述或已完成的传承人采访；
15. 讲解/展厅问答**不写入** `porcelain-reunion-progress-v1`（运行时 + 静态双守卫测试）；
16. 语音**不克隆任何真人声音**，标注「AI 合成角色语音」；原创角色声明"非真实历史人物复原"；
17. 远程讲解为**可替换适配层**（默认关闭），前端**不保存密钥**，只发最少必要上下文，不发送昵称/存档等个人数据，带超时与失败回退。

**C. 「本轮明确不做」（`docs/最终改进提示词.md` 第 228 行起）**

18. 不新增第七件器物或更多关卡；
19. 不新增更多 3D 景区；
20. 不增加物理引擎或改变碎片操作手感；
21. 不新增与文化学习无关的小游戏；
22. 不编造新的历史故事填补资料空白；
23. 不用民族服饰、图腾或纹样拼贴制造表面"民族性"；
24. 不执行真实线上部署；不生成正式二维码；不代替人工完成传承人口述核实与授权；
25. 不改写或更新 `docs/3分钟演示脚本.md` 等参赛演示材料。
