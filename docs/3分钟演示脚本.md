# 3 分钟演示录制脚本

建议录制 1920×1080 横屏，浏览器缩放 100%，关闭与项目无关的通知。此文档是录制稿，不是已录制的视频文件。

| 时段 | 画面与操作 | 讲述重点 |
| --- | --- | --- |
| 0:00—0:20 | 开始页，标题与青花瓶意象 | “《碎瓷重圆》让玩家作为数字修复师，通过指尖操作重新看见器物的经历。”说明景德镇青花意象与自制纹样 |
| 0:20—0:40 | 接受委托、阅读背景、输入昵称 | “这是一个明确标注的虚构家庭传世器设定。我们用创作手记讨论地方记忆，不把想象冒充考古证据。” |
| 0:40—1:10 | 手动拖一片、旋转 Q/E、显示提示、吸附 | “碎片只在 XY 平面移动。位置和角度都接近时才归位。6—12 片的目标在此版本落为九片。” |
| 1:10—1:35 | 阅读两段碎片记忆，打开记忆册 | “每块瓷片绑定一段 60—120 字的手记和原创纹样，解锁后可以回看。从单纯拼图进入记忆体验。” |
| 1:35—2:00 | 用演示入口补完九片，关闭最后手记 | “Voronoi 切割与 BufferGeometry 生成不规则瓷片，共享贴图和连续 UV；Raycaster、pointer 与 GSAP 完成拾取和吸附。” |
| 2:00—2:25 | 选择传统，观察浅灰线；重新选择金缮 | “传统分支在数字作品中强调轻声记录和未来判断的空间；金缮分支用金线表达接纳裂痕。这是视觉与理念的比较，真实修复需要专业评估。” |
| 2:25—2:45 | 上釉补色，完整瓶身和金线 | “立体感来自纹理明暗和局部 Bloom，没有复杂物理或自由三维旋转。粒子用于简短反馈。” |
| 2:45—3:00 | 预览、下载证书；展示昵称、编号与裂痕特写 | “我们带走的不只是一只拼好的瓶，还有署名、日期、独立编号和一次有记录的选择。” |

录制前准备：先练习手动放回第一片；演示入口每片会暂停显示手记，可以迅速点击“继续演示”。需比较两种证书时，先预览传统，再更改为金缮，上釉后重新签发。

后期仅做头尾裁切、必要字幕和音量统一，不用剪辑替代真实玩法演示。避免跳过“为什么做这个选择”的核心内容。
