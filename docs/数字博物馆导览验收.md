# 《碎瓷重圆》沉浸式数字博物馆与 AI 古人讲解 · 升级验收

本轮在既有九屏主流程内增加一套统一的「数字博物馆导览体验」，不新增第七件器物、不改变主线进度与存档规则。
新增逻辑全部走独立模块，`src/immersive.js` 只做装配与上下文联动。

---

## 一、体验设计概述

整体设计为一座存在于「窑火记忆」中的数字博物馆，美术语言统一为**墨蓝夜色 + 宣纸 + 青花 + 窑火 + 金缮裂纹 + 薄雾微光**。
叙事关系为：**一件器物 → 一项工艺 → 一群制瓷者 → 一段城市记忆 → 一次修复选择**。

六件器物对应六个主题展位：

| 展位 | 器物 | 文化学习主题 |
| --- | --- | --- |
| 一 | 花鸟纹梅瓶 | 纹样 · 绘制与日常使用 |
| 二 | 玉壶春瓶 | 官窑制度 · 检验与考古记录 |
| 三 | 云龙纹罐 | 瓷器贸易 · 文化交流 |
| 四 | 釉里红高足杯 | 窑火控制 · 失败与匠人经验 |
| 五 | 祭红釉蒜头瓶 | 民间传说与工艺事实的区分 |
| 六 | 玲珑瓷碗 | 分工 · 师徒学习与当代传承 |

展厅能力：自由环视 / 自动导览（每件 30–60 秒，可暂停·继续·跳过·退出·静音）/ 靠近聚焦照明 /
器名·年代·主题·内容属性标签 / 热点旋转缩放 / 纹样工艺热点短讲解 / 原创古人角色的出现与消散；
并提供明确的「退出近观 ×」「退出导览」「收起讲解」控制（点击热点进入近观后，`#exhibit-near` 出现，
点击即恢复展厅照明并停止讲解；切换器物同样自动退出近观）。
所有原「悬停触发」内容均已提供点击、键盘与触屏等价入口（`.hotspot-btn` 为真实按钮，可 Tab 聚焦、可回车触发）。

## 三、知识来源与回答边界

- **数据源**：`src/data/guide.js`（30 条知识条目）、`src/data/vessels.js`、`src/data/culture.js`、
  `src/data/quotes.js`、已审核的 `docs/` 资料。共 10 条统一来源（故宫博物院藏品页 / 数字文物库 /
  中国非物质文化遗产网 / 项目 ATTRIBUTION）。
- **条目构成**：主标签「史实依据」22 条、「数字示意」4 条、「原创叙事」3 条、「民间传说」1 条；
  其中 7 条标 `pending`，正文自带「待人工核实/待核实」字样。
- **来源优先级**：① 标注来源的史实资料 → ② 明确标注的民间传说 → ③ 项目原创叙事 → ④ 数字示意 → ⑤ 尚未核实。
- **回答标签**：每条回答渲染对应标签 chips，且可展开「查看资料来源」；无外部来源时显示
  「本条未附外部来源，属于项目原创叙事或数字示意」。
- **未知处理**：命中分数低于阈值或落在领域外时，统一回答
  「现有展览资料中没有足够依据回答这个问题，建议查看资料来源或由人工进一步核实。」，
  不编造史实、人物、机构背书、考古结论、采访与口述。该行为已由自动测试覆盖。

## 四、古人角色设定与原创声明

- 角色：**画坯匠 · 阿墨**（`huapei-amo`），明代景德镇画坯匠，`signature` 为「少量古意 + 现代解释」。
- 原创声明（首次出现前必展）：
  「该人物为依据相关时代制瓷工种与生活语境创作的数字角色，不是真实历史人物复原。」
- **双层结构**：古人角色只讲其时代可知的劳动、经验与感受；涉及现代研究、资料来源、内容标签与
  不确定性时，改由中性的「数字策展员」作答，避免「一个古人精通所有时代」的错觉。
- **禁答范围**（`GUIDE_CHARACTER.forbidden`）：冒充真实人物/传承人/公众人物的声音、姓名与生平；
  宣称亲历现代考古、鉴定、统计与机构合作；把传说说成工艺成因；回答超出明代景德镇制瓷语境的问题。
- **视觉**：`INK_SVG` 半透明水墨剪影 + Canvas 窑火粒子聚合成人形，轻量、可关闭、非写实全身。
  出现流程为「窑火粒子 → 聚合剪影 → 先注视器物再面向用户 → 字幕语音同步 → 结束化为光点」。

## 五、语音方案与合规说明

- `guide-voice.js` 提供两套音色：**古人角色音色**（沉静、亲切、略有叙事感）与
  **数字策展员音色**（清晰、中性，适合解释史实与来源）。
- 标注「AI 合成角色语音」；**不进行真人声音克隆，不声称复原真实古人声音，不训练未授权录音**。
- 默认音量适中；首次播放需用户主动触发；提供播放/停止/暂停/静音/字幕/文本阅读。
- 语音文本严格取自面板可见的 `answer.text`，**字幕与声音同源**。
- 无语音服务时自动回退：逐段推送字幕 + 浏览器 `speechSynthesis` 通用语音；
  静音状态不会被 `speak()` 重置，用户关闭声音后不会在切换页面时自动重开。

## 六、性能与移动端降级

- 不新增未经优化的人物 GLB；角色为 SVG + Canvas 程序化生成，延迟加载、同一时间仅一个活动角色。
- 移动端 / 低性能（`body.low-power`）与 `prefers-reduced-motion` 下自动取消粒子与大幅动作，
  仅保留淡入淡出；页面隐藏时暂停动画与语音。
- 角色消散后停止绘制并释放纹理/几何与语音资源；未新增后处理与阴影开销。
- 无障碍：热点与入口均为真实按钮，支持键盘与焦点管理；面板含 `aria-live`/`aria-label`/
  `aria-pressed`；字幕位于面板内，不遮挡器物与主按钮。
- 375px：面板 `width:376px;max-width:96vw`，窄屏下抽屉宽度随视口收缩（≤96vw），不溢出。
