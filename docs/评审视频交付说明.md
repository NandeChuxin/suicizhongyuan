## 三、视觉与声音设计

**转场（两类，均由程序生成，无外部素材）**

1. **碎瓷拼合**：把画面切成约 110 块 Voronoi 不规则瓷片，按"离撞击点的距离 + 每片随机延迟"逐片亮起；片与片的交界用金色辉光描边，呼应金缮与锔瓷的"缝线"意象。
2. **青花晕染**：以噪声扰动的径向延迟图从画面中心化开，边缘带青花蓝，用于章节调性较柔的切换。

两类转场交替使用（0.85 s），与章节内容气质对应；应用自身的"碎瓷换屏"转场则保留在流程内部，形成内外两层同构的转场语言。

**叠加层**

- **章节牌**：顶部中央，`S0x / 中文名 / ENGLISH`，淡入 3.4 s 后淡出，不遮挡主体操作区；
- **字幕**：底部居中，墨色半透底板 + 金色竖线 + 宋体，单行 ≤ 26 字，自动折行两行；
- **光标**：自绘"金环瓷点"光标，含按下态与点击涟漪，位置由录制时真实指针轨迹回放插值；
- **水印**：底部中央 14 px 的「碎瓷重圆 · 项目评审演示」。

**配乐（numpy 程序化合成，无版权素材）**

- 调式：D 羽调式（D F G A C），拨弦用谐波叠加模拟古琴/筝，长音铺底用多谐波正弦 + 慢速 LFO；
- 章节切换处固定放"气声 + 轻鼓"，与转场对齐；证书、终局、尾卡处加入瓷铃泛音；
- 全片响度约 −17 dBFS RMS，峰值 −1 dB，首尾 1–3 s 淡入淡出，避免评审现场爆音。

## 六、复现与再制作

`pipeline/` 目录保存了完整链路：

```text
pipeline/
├─ lib.mjs          # 录制库：Edge(CDP) 抓帧 + 真实指针操作 + 指针/章节打点
├─ picks.mjs        # 拼合屏碎片的屏幕坐标求解（顶点投影，非 mesh 原点）
├─ takeA.mjs        # 主流程：启程→档案柜→委托→拼合→长卷
├─ takeA2.mjs       # 抉择→金线工序→证书（带种子存档）
├─ takeB.mjs        # 三处写实考察 + 终局成就（六件全修种子）
├─ takeC.mjs        # 数字展厅 + 窑火问答
├─ takeD.mjs        # 三槽存档 / 导出 / 分享码
├─ takeE.mjs        # 手机竖屏（430×932）
├─ frames.mjs       # 按时间码抽帧（审片用）
├─ sheet.mjs        # 生成联系表（2 秒一帧拼图，用于定剪）
└─ build/
   ├─ edl.py        # 时间线：章节 / 片段 / 字幕 / 尾卡要点
   ├─ visual.py     # 叠加层与转场：章节牌、字幕、光标、Voronoi 碎瓷、青花晕染、片头尾卡
   ├─ render.py     # 解码 → 合成 → x264 输出（支持 1920×1080 与低分辨率预览）
   ├─ audio.py      # 程序化配乐与音效合成（输出 WAV）
   └─ makesrt.py    # 由时间线导出 SRT 与章节索引
```

再生成步骤（脚本内为绝对路径，迁移后需改常量）：

```powershell
# 1) 起本地服务
npm run dev                       # http://127.0.0.1:5173
# 2) 录屏（每个 take 约 1–5 分钟，输出 take.mp4 + timing.json）
node pipeline\takeA.mjs
node pipeline\takeA2.mjs
node pipeline\takeB.mjs ; node pipeline\takeC.mjs ; node pipeline\takeD.mjs ; node pipeline\takeE.mjs
# 3) 合成画面（VW/VH/FPS/TAG 控制规格，ONLY_INTRO=1 可只出片头）
$env:VW='1920'; $env:VH='1080'; $env:FPS='30'; $env:TAG='full'
python pipeline\build\render.py
# 4) 合成配乐并合流
python pipeline\build\audio.py full
ffmpeg -i out\full.mp4 -i out\full.wav -c:v copy -c:a aac -b:a 192k -shortest final.mp4
python pipeline\build\makesrt.py full
```

依赖：Node 24 + `playwright-core`（channel: msedge）、FFmpeg 8、Python 3（numpy / Pillow）。

## 七、已知边界

- 录制环境为无头 Edge + ANGLE/D3D11，抓帧率约 20–70 fps（随场景复杂度变化），成片统一 30 fps，静态段落有轻微顿帧；
- 考察章节的 3D 场景为程序化白模 + 雾效，暗部与「夜」光照在录制环境偏黑，片中只选取了可读性较好的机位与光照；
- 字幕为画面内烧录，如需改词请用 `.srt` + 时间线重出；`edl.py` 中每个章节的字幕都在同一处维护。
